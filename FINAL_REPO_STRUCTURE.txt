MAIN ENTRYPOINTS:
================

1. Training:     python scripts/train.py
2. Inference:    python scripts/infer.py
3. Evaluation:   python scripts/eval.py
4. Submission:   python scripts/submit.py
5. Preprocessing: python scripts/build_sequences.py

PACKAGE STRUCTURE:
==================

All code is organized under src/nfl_bdb/:
- nfl_bdb.models       - Model architectures
- nfl_bdb.training     - Training code
- nfl_bdb.inference    - Inference code
- nfl_bdb.evaluation   - Evaluation code
- nfl_bdb.preprocessing - Data preprocessing
- nfl_bdb.utils        - Utilities

CONFIGURATION:
==============

Main config: configs/default.py
Compatibility: config.py (wrapper)
